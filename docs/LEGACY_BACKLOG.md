# Бэклог Paints Chat

## P1 — качество поиска

- Добавить нормализацию русского текста: простой стемминг, `ё/е` и таблицу
  транслитерации брендов (`кнауф → knauf`, `церезит → ceresit`,
  `тиккурила → tikkurila`).
- Добавить автоматические тесты retrieval: словоформы, транслитерация брендов,
  продолжение диалога, отсутствующий товар и сравнение двух товаров.
- Выбрать следующий поисковый движок: SQLite FTS5 без зависимостей или BM25
  через `rank_bm25`.
- Выполняется в Smart-search V1.1: локальный hybrid embedding entity resolution только для опечаток брендов/названий. Гибрид BM25/FTS5 + embeddings для общего semantic retrieval остаётся будущей задачей.

## P2 — безопасность и эксплуатация

- Заменить временный Quick Tunnel на именованный Cloudflare Tunnel, привязать
  постоянный поддомен через DNS и хранить авторизацию только в Cloudflare.
- Ограничить количество сообщений в истории и общий размер HTTP-запроса.
- Добавить rate limiting по IP для сценария прямого внешнего доступа.
- Добавить аутентификацию, если сервер будет публиковаться без Cloudflare
  Access или другого внешнего шлюза.
- Перейти с `print` на модуль `logging` с безопасной фильтрацией секретов.
- Добавить endpoint `/health` без платного обращения к Gemini.

## P3 — наблюдаемость и скорость

- Логировать обезличенные диалоги и найденные товары в SQLite или JSONL.
- Добавить кэш одинаковых нормализованных вопросов с инвалидированием при
  обновлении каталога.

## P4 — UX и качество диалога

- Довести структурирование ответа: короткое вступление, отдельные смысловые
  секции, товары под соответствующим текстом и единообразный итоговый вывод.
- Добавить наводящие вопросы, когда для подбора не хватает назначения,
  поверхности, площади, условий эксплуатации, бюджета или фасовки.
- Подготовить для модели компактный гайд по каталогу: иерархия категорий,
  назначение основных групп и типичные сценарии применения материалов.
- Сократить ответы: ограничить вводную часть, число повторов характеристик и
  объём итогового пояснения после карточек.
- Заменить однообразную надпись «печатает ответ» на несколько коротких
  тематических статусов, например «Ищу в каталоге» и «Сверяю характеристики».

## P5 — функции продукта

- Перейти от постоянной передачи топ-25 к function calling с инструментом
  `search_catalog(query)` и ограничением числа вызовов.
- Добавить отдельный семантический поиск по пользовательской задаче (не путать с узким entity resolution V1.1).
- Перенести товарный каталог из JSON в SQL-хранилище (начать с SQLite) и
  выделить слой доступа к данным, чтобы впоследствии заменить СУБД без
  переписывания логики чата.

## P6 — архитектура при разрешении внешних зависимостей

- Разделить `server.py` на `retrieval.py`, `llm.py`, `prompts.py` и HTTP-слой.
- Рассмотреть FastAPI + Uvicorn + Pydantic и официальный `google-genai` SDK.
- Добавить `pytest`, Dockerfile и автоматическую проверку перед публикацией.
